# 給与管理クラウド 操作マニュアル（日本語）

更新日: 2026-07-26

## 1. ログイン

1. ログイン画面でメールアドレスとパスワードを入力します。
2. ログイン後、権限に応じて利用可能なメニューだけ表示されます。
3. 社員本人権限の場合、自分の明細だけ閲覧できます。

## 2. 社員管理

1. 「給与管理」から社員一覧を開きます。
2. 社員番号、氏名、メール、既定の扶養人数、給与区分、基本給、固定残業手当、職位などを入力します。
3. 雇用保険適用、社会保険加入、保険料適用金額を社員ごとに設定できます。
4. 職位が未入力の場合、給与明細PDFには「SE」と出力されます。

## 3. 年度・料率管理

1. 税金、社会保険料率は年度ごとに登録します。
2. 健康・介護保険料率、厚生年金保険料率、雇用保険料率、子ども・子育て支援金を分けて入力します。
3. 小数点は6桁まで入力できます。
4. 住民税は給与入力時に社員ごと、月ごとに入力します。

## 4. 所得税表

1. 所得税表CSVをインポートします。
2. CSV形式は `fiscalYear,dependentCount,minTaxable,maxTaxable,taxAmount` です。
3. 給与計算時は年度、扶養人数、課税対象金額から自動で税額を検索します。

## 5. 給与入力

1. 支給月を選択します。
2. 社員を選択し、基本給、固定残業手当、手当、住民税、寮使用料、備考などを入力します。
3. 「前回利用」は選択中社員本人の過去入力だけを参照します。
4. 28日以降は前月以前の通常更新が制限されます。必要な場合は強制変更を選択して保存します。
5. 支給日は会社運用に合わせ、システム日が25日以下の場合は前月を初期表示します。

## 6. 賞与入力

1. 月給とは別に賞与を登録します。
2. 賞与がない社員は登録不要です。
3. 通常賞与月は4月末、10月末を想定しています。
4. 賞与所得税は現状、給与と同じ所得税表ロジックで計算します。

## 7. PDF出力

1. 社員ごとの給与明細PDFをダウンロードできます。
2. 指定月範囲で一括出力できます。
3. 出力方法は個別PDFまたは1つのPDFにまとめる方式を選択できます。
4. 「賞与含み」にチェックした場合、対象期間の賞与明細も含めます。
5. ファイル名は給与明細が `給与明細_年月_名前`、一括出力が `給与明細_開始年月_終了年月` です。

## 8. 権限管理

1. 「管理メニュー」からユーザ管理と権限管理を開きます。
2. 権限管理ではロール一覧、ロール追加、非表示、ロールごとのメニュー権限を設定できます。
3. メニュー表示、閲覧、更新、全件、自分のみを子メニュー単位で設定できます。
4. ユーザ登録時は利用可能なロールを選択し、必要に応じてユーザ個別の権限を上書きできます。
5. 権限管理では、給与管理、SES管理、管理メニューごとに表示、閲覧、更新、全件を一括チェックできます。
6. ロール保存や権限保存に失敗した場合、権限管理画面内にエラーメッセージが表示されます。

## 9. メッセージ表示

1. 保存、検索、PDF出力などの操作結果は、ログイン後の操作画面でメニュー上部に表示されます。
2. ログイン画面にはログイン失敗などログイン専用メッセージだけ表示されます。
