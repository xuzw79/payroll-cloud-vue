# Payroll Submenus Design

## Goal

給与管理画面をSES管理と同じ子メニュー方式に整理し、画面を見やすくする。

## Scope

- 対象はフロントエンド表示整理。
- 給与計算、所得税計算、PDF出力、CSV出力、保存APIは変更しない。
- 権限モデルは既存の `PermissionMenu` を利用する。
- `handoff.md`、日本語/中国語マニュアル、Excelマニュアルを更新する。

## Payroll Submenus

| 子メニュー | 権限 | 主な内容 |
| --- | --- | --- |
| 社員管理 | `PAYROLL_EMPLOYEES` | 社員一覧、社員基本情報、職位、社会保険、雇用保険 |
| 給与入力 | `PAYROLL_INPUT` | 支給月、社員検索、給与入力、給与保存、給与PDF |
| 賞与入力 | `BONUS_INPUT` | 賞与入力、賞与保存、賞与PDF |
| 明細出力 | `PAYSLIP` or `BONUS_SLIP` | 期間指定PDF一括出力、給与CSV、賞与CSV、明細確認 |
| 年度料率 | `RATES` | 年度料率入力、料率保存、年度一覧 |
| 所得税表 | `TAX_IMPORT` | 所得税表CSVインポート、読込件数 |

## UI Behavior

- 給与管理メインメニューを開いたら、利用可能な先頭子メニューを表示する。
- 子メニューはSES管理と同じ `.sub-menu` スタイルを使う。
- 子メニュー切替時は前画面のメッセージをクリアする。
- 支給月、社員検索、社員一覧は必要な子メニューだけで表示する。
- 明細出力は範囲ダウンロード操作を中心にまとめる。

## Constraints

- 既存の計算ロジックやAPI呼び出しは変更しない。
- 既存の権限管理画面に新しい権限項目は追加しない。
- 既存の青い業務システムCSSを維持する。
- スマートフォンでもボタン名と年月入力が見切れないようにする。

## Verification

- `cmd /c npm run build` が成功すること。
- 主要子メニューの表示条件が権限に対応すること。
- メニュー切替時にメッセージが残らないこと。
