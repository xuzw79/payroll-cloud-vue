# SES管理 操作マニュアル（日本語）

更新日: 2026-07-26

## 1. 基本方針

SES管理は給与管理と分離し、メニュー配下の子メニューで管理します。給与データへ直接影響しないように、契約、請求、外注費、売上集計を別管理します。

## 2. 取引先管理

1. 取引先を登録します。
2. 法人だけでなく個人事業主も登録できます。
3. 取引先所属の別会社従業員を登録できます。
4. 一時利用の取引先は登録せず、契約登録時に取引先名を手入力できます。

## 3. 契約管理

1. 契約名、契約番号、契約先、契約区分、契約期間、品名・摘要を入力します。
2. 契約には複数メンバーを登録できます。
3. メンバーは自社社員、別会社従業員、または指定なしを選択できます。
4. メンバーなしでも契約金額を入力できます。
5. 契約金額は税抜き、税込みを選択できます。デフォルトは税抜きです。
6. 契約終了した案件は通常検索対象外です。「終了契約」をチェックすると検索対象に含めます。

## 4. 単価設定

1. 定額契約: 月額固定で請求します。作業時間入力は不要です。
2. 時間範囲契約: 基準時間、控除時給、超過時給を入力します。作業時間から控除・超過を自動計算します。
3. 時給契約: 時給と営業時間を入力します。営業時間を超えた場合は超過時給を適用できます。

## 5. 請求管理

1. 請求対象月は前月を初期表示します。
2. 契約から請求対象データを検索します。
3. 定額は作業時間入力不要です。
4. 精算時間範囲または時給の場合、作業時間を入力します。入力欄には作業員名を表示します。
5. 同一契約・同一月の請求書は重複作成しません。
6. 請求書番号未入力の場合、`年月-001` 形式で自動採番します。
7. 請求書日付は `2026年7月31日` の形式で出力します。
8. 社印は社名付近に配置し、住所などに重ならないようにします。

## 6. 外注費管理

1. 仕入契約の場合、月末に外注費を登録します。
2. 外注費は税抜き、税込みを区別して入力します。
3. 外注費登録済みかどうかを画面上で確認できます。
4. 登録済み外注費は年間売上・支出集計の支出額に反映されます。

## 7. 年間売上・利益

1. 自社情報の決算月から初期決算年度を表示します。
2. 月別に縦並びで売上、支出、差額を表示します。
3. 売上入金額は請求書金額と個別売上入力を合算します。
4. 支出額は給与、賞与、年金支払額、外注費、個別支出入力を合算します。
5. 差額は売上入金額から支出額を差し引いて表示します。

## 8. マスタ管理

1. 自社情報でシステム名を設定できます。
2. 設定したシステム名はログイン画面と画面左上のタイトルに表示されます。
3. 未設定の場合は「給与管理クラウド」を表示します。

## 9. エラー表示

1. 契約登録、請求書作成、外注費登録などでエラーが発生した場合、赤字でSES管理の対象サブメニュー直下に表示します。
2. 契約管理のエラーは契約管理メニュー直下、取引先管理のエラーは取引先管理メニュー直下に表示します。
3. 保存、検索、PDF出力などの操作完了メッセージは、緑色のtoastで画面右上に表示され、自動で消えます。
4. SES管理内でサブメニューを切り替えると、前の画面のメッセージはクリアされます。
