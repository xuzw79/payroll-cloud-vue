# 工资管理云 操作手册（中文）

更新日: 2026-07-26

## 1. 登录

1. 在登录画面输入邮箱和密码。
2. 登录后，只显示当前权限可使用的菜单。
3. 员工本人权限只能查看自己的工资明细。

## 2. 员工管理

1. 从“工资管理”进入员工列表。
2. 输入员工编号、姓名、邮箱、默认扶养人数、工资区分、基本工资、固定加班补贴、职位等。
3. 可以按员工设置雇用保险适用、社会保险加入、保险费适用金额。
4. 职位为空时，工资明细PDF默认输出“SE”。

## 3. 年度和费率管理

1. 税率、社会保险费率按年度维护。
2. 健康护理保险、厚生年金、雇用保险、儿童育儿支援金分开录入。
3. 小数点最多支持6位。
4. 住民税在工资录入时按员工、月份录入。

## 4. 所得税表

1. 导入所得税表CSV。
2. CSV格式为 `fiscalYear,dependentCount,minTaxable,maxTaxable,taxAmount`。
3. 计算工资时，系统按年度、扶养人数、课税对象金额自动查表。

## 5. 工资录入

1. 选择支付月份。
2. 选择员工，输入基本工资、固定加班补贴、补贴、住民税、宿舍费、备注等。
3. “使用上次内容”只引用当前员工自己的历史录入。
4. 28日以后，前月及以前数据默认不能普通更新。如需修改，选择强制变更后保存。
5. 按公司25日发上月工资的规则，系统日小于等于25日时默认显示前月。

## 6. 奖金录入

1. 奖金与月工资分开录入。
2. 没有奖金的员工无需录入。
3. 通常奖金月份按4月底和10月底处理。
4. 当前奖金所得税使用与工资相同的所得税表逻辑计算。

## 7. PDF输出

1. 可下载单个员工的工资明细PDF。
2. 可按月份范围批量下载。
3. 输出方式可选择多个PDF或合并成一个PDF。
4. 勾选“包含奖金”时，期间内的奖金明细也会一起输出。
5. 文件名规则: 工资明细为 `給与明細_年月_姓名`，批量输出为 `給与明細_开始年月_结束年月`。

## 8. 权限管理

1. 从“管理菜单”进入用户管理和权限管理。
2. 权限管理支持角色列表、角色新增、隐藏、按角色设置菜单权限。
3. 可以按子菜单设置是否显示、查看、更新、全件、自身数据。
4. 用户注册时选择可用角色，必要时可以按用户单独覆盖菜单权限。
5. 在权限管理中，可以按工资管理、SES管理、管理菜单为单位，一次勾选显示、查看、更新、全件。
6. 角色保存或权限保存失败时，错误信息会显示在权限管理画面内。
