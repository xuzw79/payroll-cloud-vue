# SES管理 操作手册（中文）

更新日: 2026-07-26

## 1. 基本方针

SES管理与工资管理分离，通过菜单下的子菜单管理。合同、发票、外包成本、销售利润单独管理，尽量不影响既有工资功能。

## 2. 客户管理

1. 注册客户或合作公司。
2. 支持法人和个人事业主。
3. 可以在客户下面登记其他公司的员工。
4. 临时客户可以不登记客户主数据，在合同录入时直接手动输入客户名称。

## 3. 合同管理

1. 输入合同名、合同编号、合同对象、合同区分、合同期间、品名和摘要。
2. 一个合同可以登记多个成员。
3. 成员可以选择本公司员工、其他公司员工，或不指定。
4. 没有成员也可以录入合同金额。
5. 合同金额可以选择税前或税后，默认税前。
6. 已结束合同默认不作为搜索对象。勾选“结束合同”后才包含在搜索结果中。

## 4. 单价设置

1. 定额合同: 按月固定金额开票，不需要输入工作时间。
2. 时间范围合同: 输入标准时间、扣除时给、超出时给，系统按工作时间自动计算扣除和超出金额。
3. 时给合同: 输入时给和营业时间。超过营业时间时可以使用超出时给。

## 5. 发票管理

1. 发票对象月默认显示前月。
2. 从合同检索需要开票的数据。
3. 定额合同不需要输入工作时间。
4. 时间范围或时给合同时，需要输入工作时间，输入栏显示作业人员姓名。
5. 同一合同、同一月份不允许重复创建发票。
6. 发票编号未输入时，按 `年月-001` 形式自动编号。
7. 发票日期按 `2026年7月31日` 格式输出。
8. 公司印章放在公司名附近，避免与地址等文字重叠。

## 6. 外包成本管理

1. 采购合同需要在月末登记外包成本。
2. 外包成本输入时区分税前和税后。
3. 画面上可以确认是否已经登记外包成本。
4. 已登记外包成本会反映到年度销售和支出统计的支出金额中。

## 7. 年度销售和利润

1. 根据自社信息中的决算月初期显示决算年度。
2. 按月份纵向显示销售、支出和差额。
3. 销售入金额由发票金额和个别销售输入合计。
4. 支出额由工资、奖金、年金支付额、外包费和个别支出输入合计。
5. 差额为销售入金额减去支出额。

## 8. 错误信息

合同保存、发票创建、外包成本登记等发生错误时，错误信息会显示在当前操作画面上。
